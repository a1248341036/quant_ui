# Code of Conduct

## Our standard

We want this project to be useful to people with different backgrounds and levels of experience.
Participants are expected to be respectful, constructive, and specific when discussing data quality,
implementation choices, and competing tools.

Unacceptable behaviour includes harassment, discrimination, personal attacks, publishing private
information, and deliberately misleading reports about data or source behaviour.

## Enforcement

Report problems privately to the maintainer through the security contact listed in
[SECURITY.md](SECURITY.md) when the report contains sensitive information. Otherwise, contact the
maintainer through the repository issue or discussion system. Reports will be reviewed and handled
as promptly as a personal open-source project permits.
