# quant_ui「代码」Tab 使用教程

> 适用版本：当前 qweave 研究工作台
>
> 项目路径：`D:\Quant\quant_ui`
>
> Web 地址：`http://127.0.0.1:17891/`

---

## 1. 这个 Tab 是做什么的

当前「代码」Tab 已经从旧的事件策略编辑器切换为：

```text
qweave 因子研究
    ↓
股票级因子值
    ↓
因子评价
    ↓
选择一个因子作为交易 score
    ↓
TopN / 动态比例选股
    ↓
日线交易回测
```

它现在不是旧版的：

```text
STRATEGIES
EVENT_STRATEGIES
on_bar(ctx, bar)
```

也不是直接编写一个完整的订单执行程序。

当前代码 Tab 的代码职责是：

```text
定义一组 qweave 因子表达式
```

交易职责由后端交易回测引擎负责：

```text
TopN
动态持仓数量
T+1
涨跌停
停牌
100 股整手
手续费
滑点
流动性约束
```

## 2. 第一次使用：推荐操作流程

### 步骤 1：打开项目

打开：

```text
http://127.0.0.1:17891/
```

进入左侧：

```text
代码
```

如果页面看起来还是旧版本，执行：

```text
Ctrl + F5
```

### 步骤 2：选择预制代码

在「研究代码模板」中选择一个预制模板：

```text
预制 · Alpha158 · 常用 30 因子
预制 · Alpha158 · 全量
预制 · WorldQuant Alpha101
预制 · GTJA Alpha191
```

第一次建议使用：

```text
Alpha158 · 常用 30 因子
```

因为运行时间和返回数据量相对可控。

### 步骤 3：点击“解析因子”

解析不会加载全市场行情，也不会运行回测。

它只检查：

- Python 代码能否导入
- 是否存在有效的 qweave 因子协议
- 实际返回多少个因子
- 因子名称是什么

解析成功后，页面会出现类似：

```text
KMID、KLEN、KMID2、KUP、...
```

这些就是后续可以选择为回测信号的股票级因子。

### 步骤 4：设置研究参数

先使用下面这套参数：

```text
股票池：科技TMT
Alpha 集：alpha158
开始：2025-01-01
结束：当前数据最新日期
horizon：1,5,20
分位数：10
最小截面数：30
成本 bps：8
```

### 步骤 5：先点击“运行 qweave”

这个按钮只做因子研究，不做交易回测。

它会计算：

- 每只股票的因子值
- 每个交易日的截面 IC
- Rank IC
- 分位数组收益
- 多空组合收益
- 换手
- 覆盖率
- 最新交易日股票因子排名

先看因子有没有研究价值，再进行交易回测。

### 步骤 6：选择“回测信号因子”

在“回测信号因子”下拉框中选择一个具体因子，例如：

```text
MA60
ROC20
KMID
```

如果不选择，系统会自动使用因子评估排名第一的因子。

注意：

```text
Top 因子评估排名第一
```

不等于：

```text
一定适合作为最终交易策略
```

还需要检查样本外表现、回撤、换手和成本敏感性。

### 步骤 7：设置交易回测参数

第一次建议：

```text
回测 TopN：10
选股数量模式：固定 TopN
回测频率：每周
回测资金：100000
最少持仓数：1
最多持仓数：不限制
```

然后点击：

```text
研究并回测 TopN
```

系统会先运行 qweave，再把股票级 score 交给日线交易回测引擎。

## 3. 代码到底要怎么写

### 3.1 最小代码协议

代码至少要满足下面两种协议之一。

#### 写法 A：使用 `ALPHAS`

```python
import qweave

ALPHAS = [
    # qweave 因子表达式
]
```

#### 写法 B：定义 `build_alphas()`

```python
import qweave

def build_alphas():
    return [
        # qweave 因子表达式
    ]
```

每个元素必须是 qweave 表达式，并且能够产生因子名称。

### 3.2 最简单的推荐写法

实际使用时，建议先选择预制模板，然后只修改：

```python
ALPHA_SET = "alpha158"
ALPHA_LIMIT = 30
```

例如切换到 Alpha101：

```python
ALPHA_SET = "alpha101"
ALPHA_LIMIT = 30
```

例如计算 Alpha191 前 50 个：

```python
ALPHA_SET = "alpha191"
ALPHA_LIMIT = 50
```

当前标准模板是：

```python
import qweave

ALPHA_SET = "alpha158"
ALPHA_LIMIT = 30
ALPHAS = []
```

`ALPHAS = []` 表示使用页面参数选择的标准 Alpha 集。

### 3.3 自定义代码目前的边界

当前代码 Tab 支持的是：

```text
定义因子表达式
```

不建议在这里写：

```python
def main():
    # 自己读取 parquet
    # 自己循环交易
    # 自己输出净值
```

因为行情加载、标签、评价和交易执行已经由后端统一处理。

当前不要依赖旧协议：

```python
STRATEGIES = {...}
EVENT_STRATEGIES = {...}
build_factor_frames(...)
```

这些属于旧交易策略代码，不是当前 qweave Tab 的主要协议。

## 4. 研究参数说明

### 4.1 股票池

当前常用选择：

```text
科技TMT
沪深300+中证500+中证1000
ETF
场外基金
```

它决定：

```text
哪些股票参与因子计算和横截面评价
```

因子仍然是每只股票自己的因子值，不是把整个股票池压成一个因子。

例如：

```text
date        code      MA60
2025-01-02  000001    0.952
2025-01-02  000333    1.041
2025-01-02  600519    0.981
```

### 4.2 Alpha 集

选择要计算的标准因子集合：

```text
Alpha158
Alpha101
Alpha191
自定义代码
```

### 4.3 因子数量上限

例如：

```text
Alpha158 + 因子数量上限 30
```

表示只计算 Alpha158 中的前 30 个因子。

它不是股票数量，也不是 TopN。

### 4.4 Horizon

例如：

```text
1,5,20
```

表示分别评价：

```text
未来 1 个交易日收益
未来 5 个交易日收益
未来 20 个交易日收益
```

`MA60` 中的 60 是因子计算窗口，和 `horizon=20` 不是一回事。

### 4.5 分位数

```text
分位数 = 10
```

表示每天按因子值将股票分成 10 组：

```text
Q1、Q2、...、Q10
```

它不是选 Top10 股票。

主要用于：

- 分组收益
- 多空收益
- 判断分组是否单调

### 4.6 最小截面数

```text
最小截面数 = 30
```

表示某天至少要有 30 只股票拥有有效因子值，才计算当天 IC 和分组收益。

建议：

```text
科技TMT：20~30
大股票池：50~100
```

### 4.7 成本 bps

```text
1 bps = 0.01%
8 bps = 0.08%
```

这个参数用于 qweave 因子多空研究的成本估计。

它和下面的交易回测成本不同：

```text
qweave 成本 bps：研究层的多空成本估计
买入费率 / 卖出费率：交易回测实际扣除的费用
```

## 5. 研究结果怎么看

### 5.1 Top 因子评估

这一张表是因子级结果：

```text
因子
H
IC 均值
Rank IC
ICIR
多空年化
多空 IR
换手
```

它回答：

```text
这个因子整体有没有选股能力？
```

它不是单只股票列表。

### 5.2 最新交易日股票因子排名

这张表是股票级结果：

```text
日期
方向
排名
代码
因子
因子值
截面分位
```

它回答：

```text
这个因子今天给哪些股票高分？
哪些股票低分？
```

### 5.3 IC

IC 是当天股票截面上：

```text
因子值
和
未来收益
```

之间的相关性。

### 5.4 Rank IC

Rank IC 比较的是：

```text
因子排名
和
未来收益排名
```

因子选股通常需要同时看 IC 和 Rank IC。

### 5.5 多空年化

通常表示：

```text
高因子组收益 - 低因子组收益
```

这是研究组合，不等于你的真实账户净值。

## 6. 交易回测参数说明

### 6.1 回测信号因子

这是从 qweave 输出的股票级因子中选择一个，作为交易分数：

```text
score = 该股票当天的因子值
```

例如选择 `MA60`：

```text
每天计算所有候选股票的 MA60
按 MA60 排名
根据方向和选股模式构造组合
```

注意：当前默认是按 score 从高到低选择。

因此对于需要“低值更好”的因子，要确认研究方向；当前第一版回测信号选择主要适合高值排序，低值因子需要后续增加明确的方向选项或在代码中反向输出。

### 6.2 固定 TopN

```text
选股数量模式：固定 TopN
回测 TopN：10
```

每次调仓最多选 10 只股票。

### 6.3 动态比例

```text
选股数量模式：按有效股票比例
动态比例：0.10
```

表示每个调仓日选择有效股票中排名靠前的 10%。

例如：

```text
有效股票 89 只 → 选 9 只
有效股票 60 只 → 选 6 只
有效股票 150 只 → 选 15 只
```

### 6.4 最少和最多持仓数

```text
最少持仓数：3
最多持仓数：20
```

动态比例计算后会受到这两个边界约束：

```text
实际持仓数 >= 最少持仓数
实际持仓数 <= 最多持仓数
```

### 6.5 回测频率

```text
每日
每周
每月
```

表示调仓频率，不是行情数据频率。

当前研究数据是日线，交易执行也是日线。

### 6.6 买入和卖出费率

默认：

```text
买入费率：0.08%
卖出费率：0.13%
```

回测时会实际从现金中扣除。

### 6.7 滑点 bps

例如：

```text
滑点 = 5 bps = 0.05%
```

买入价上浮，卖出价下浮。

### 6.8 单笔成交参与率

例如：

```text
单笔成交参与率 = 0.05
```

表示单笔交易金额不能超过近 20 日平均成交额的 5%。

设置为 0 表示不限制。

### 6.9 成交额过滤分位

默认：

```text
0.2
```

用于过滤成交额较低的股票，不是手续费参数。

## 7. “运行 qweave”和“研究并回测 TopN”的区别

### 运行 qweave

只做：

```text
因子计算
标签
IC
Rank IC
分组收益
多空研究
股票级排名
```

适合回答：

```text
这个因子有没有研究价值？
```

### 研究并回测 TopN

执行：

```text
因子计算
    ↓
选择因子作为 score
    ↓
动态或固定选股
    ↓
交易执行
    ↓
净值和回撤
```

适合回答：

```text
按这个因子实际日线交易，结果如何？
```

```text
回测资金：100000

最多持仓数：20
```

然后点击：


```text

动态比例：0.10
最少持仓数：5
```


- 最大回撤
- Sharpe
- 换手
- 成交成本
- 实际持仓数量
- 样本外表现

## 9. 如何判断一个因子能不能进入策略

不要只看某一行 Top 因子结果。

至少检查：

### 研究层

- [ ] IC 均值不是只有极小正数
- [ ] Rank IC 方向一致
- [ ] ICIR 不过低
- [ ] 分组收益尽量单调
- [ ] 多空收益不是只由少数几天贡献
- [ ] 不同 horizon 不是只有一个偶然有效
- [ ] 不同股票池仍有一定稳定性

### 交易层

- [ ] 扣成本后仍有收益
- [ ] 滑点增加后没有完全失效
- [ ] 换手可接受
- [ ] 实际成交数量不是长期严重不足
- [ ] 最大回撤可承受
- [ ] 没有明显行业或市值偏置
- [ ] 样本外仍然有效

## 10. 当前版本的已知边界

当前代码 Tab 已经支持：

- [x] qweave 预制代码
- [x] 自定义 qweave 代码协议
- [x] 因子解析
- [x] 股票级因子计算
- [x] 因子评价
- [x] 最新股票排名
- [x] 单因子 score 到 TopN 回测
- [x] 固定 TopN
- [x] 动态有效股票比例
- [x] 最少 / 最多持仓数
- [x] 手续费、滑点、流动性约束

当前还需要继续完善：

- [ ] qweave 直接接入 ROE、PB、EP 等财务因子
- [ ] 多个 qweave 因子做 Rank / Z-Score 后合成综合 score
- [ ] 明确的因子方向选择
- [ ] 行业中性化和市值中性化
- [ ] 单股因子时间序列查询
- [ ] 组合权重和换手明细
- [ ] Walk-forward 和样本外评估
- [ ] 独立导出 score Parquet

## 11. 一句话记忆

```text
预制代码：决定计算哪些因子
股票池：决定对哪些股票计算
horizon：决定预测未来多久
分位数：决定研究时分几组
回测信号因子：决定用哪个因子交易
TopN / 动态比例：决定选多少股票
回测频率：决定多久调仓
手续费和滑点：决定交易后还剩多少收益
```

最终目标是：

```text
因子研究不是策略本身。
因子经过处理后生成 score，
score 再经过组合构建和交易执行，
才形成完整的日线策略。
```
