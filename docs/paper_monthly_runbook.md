# 月频模拟盘/实盘操作手册（2026-11 版）

> 配套报告：`docs/strategy_caliber_report_20261126.md`（口径、频率、风险画像与全部实测）。
> 本手册只写"每月怎么操作、看什么、什么情况停手"。

## 1. 用哪套参数

| 项 | 值 | 说明 |
|---|---|---|
| 频率 | **月频** | 日频/周频在真实成本下逐年可负，不要用 |
| 持仓数 | 5 万 → 20 只；3 万 → 10 只；1 万 → 8~10 只 | 每只预算必须 ≥1200 元，否则收益断崖 |
| 权重 | 等权 | score 加权在滚动窗口上不稳定 |
| 成本口径 | spread_bps=22、slippage_bps=5、min_commission=5、impact_coef=0.2 | 与回测一致 |
| 池 | 低价池（pred 已按 close≤10 过滤），amount_q=0 | alpha 在低流动性尾部，代价是容量受限 |

样本外预期（2025-01~2026-11，真实成本）：**超额 +17%/年，最大回撤 -18%**。
最近 6 个月实测是 **-15% 绝对收益**（同期基准约 -30%）——超额为正不代表不亏钱。

## 2. 每月操作流程

**月末最后一个交易日 收盘后（15:30 以后）**

```powershell
# 1) 先把分数补到最新（训练/门禁不跑，只做推理）
.venv\Scripts\python.exe scripts\predict_ml_composite.py --model latest ^
  --start <上次日期> --end <今天> --channel demo --append --warmup-days 400

# 2) 跑模拟盘（会按 pred 重算并重写账户状态）
.venv\Scripts\python.exe scripts\paper_offline_run.py <今天>

# 3) 看名单
#    前端：Quant UI → 模拟盘 → 账户 #7（真实成本口径）
```

**次月第一个交易日 开盘**

按 #7 的目标名单成交（开盘价附近挂单即可）。名单在 `paper_positions` 表或前端持仓页。

## 3. 每月要核对的三个数

1. **当月超额**（策略收益 − 基准收益）：单月为负是正常的，看滚动 12 个月。
2. **实际成交与名单的偏离**：拒单率 > 10% 说明资金/持仓数不匹配（每只预算不足）。
3. **最大回撤**：历史最深 -40%（六年口径）。超过这个数要停下来重新评估，不是"再等等"。

## 4. 什么情况停手

- 滚动 12 个月超额为负 **且** 最大回撤超过 -40% → 停，回到回测排查。
- pred 断供（`data/stock/pred_demo.parquet` 最新日期落后超过 5 个交易日）→ 停，先补分数。
  历史上曾因断供导致账户被迫全现金，"看起来没亏"其实是空仓。
- 模型 IC 连续两个季度低于 0.03 → 停，重新训练与门禁。

## 5. 已知口径陷阱

| 陷阱 | 后果 | 怎么避免 |
|---|---|---|
| 用 `amount_q=0.2`（引擎默认） | 剔除 am20 最低 20%，正好切掉 alpha 尾部，超额转负 | 门禁与模拟盘都必须传 `amount_q=0` |
| 拿 `_compute_targets` / `_execute_rebalance` 当执行路径 | **这两个函数没有调用点**，改了不生效 | 真路径是 `_run_one_factor` → `run_backtest` |
| 用日频回测数字做决策 | 真实成本下日频逐年可负 | 只看月频 |
| 用六年全段年化做预期 | 2020-11~2024-12 是训练区间，样本内 | 只看 2025-01 起的样本外 |
| 分批重建面板后不复核 | 列集被裁到首批（211 vs 232 列），pred 与生产秩相关掉到 0.39 | 建完必须比对生产口径秩相关，应 >0.99 |

## 6. 各账户用途

| 账户 | 配置 | 用途 |
|---|---|---|
| #7 | 月频 top10 + 真实成本 | **主账户，看它** |
| #8 | 月频 top20 + 零成本 + vol target 25% | 分散化对照（注意 top20 在最近 6 个月反而更差） |
| #9 | 月频 top5 + 零成本 | 低波动对照（回撤 -13.5%，收益也低） |
