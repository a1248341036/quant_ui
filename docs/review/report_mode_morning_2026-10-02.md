## 二、回筛结论（问题的定性）

**用户的质疑成立**：靠"简单一行因子"没效果，且这不是感觉——

| 分组（26,707 次历史评估 / 167 run） | 达双门槛率(\|IC\|≥0.02 且 \|ICIR\|≥0.28) |
|---|---|
| 1 算子 | **1.4%** |
| 1 字段 | **0.1%** |
| 4+ 算子 | **8.2%** |
| 含结构/交互算子 | **9.1%** |
| 3+ 字段 | **11.2%** |

→ **"复现研报里那条简单公式"这个目标本身是错的**（必然产出无效因子）。
研报价值在**结构**（门控/合成/残差/择时/跨面），不在公式。

**报告里有结构吗？有**：LLM 回筛 40 篇 → 有原文公式的报告 **70%**、随机报告 **50%** 提出可复现结构，
且 LLM 给出的目标具体可执行（如"GMSD 前 2/3 → SIRD 前 50% → PB 最低 1/3 三步筛选"）。

**题面 A/B（17 篇 × 2 组）**：给公式 → 15/17 **照抄**；只给描述+要素清单 → 65% 自行复现出原式、
字段重叠同为 **90%**。→ 给公式只提高"错误传播效率"，不提高复现质量。
