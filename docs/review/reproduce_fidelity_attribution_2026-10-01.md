# 复现质量归因：是"研报公式问题"还是"复现质量问题"（2026-10-01）

> 口径：昨夜（2026-10-01 00:12–07:16 的 7 个 run + 11:22 补跑 1 个）研报模式实测数据。
> 数据源：`question_state_report.jsonl`（课题状态机）、各 run `steps.log`/`run_*.jsonl`、
> `factor_records_pilot.jsonl`（原文公式）、`research_questions.jsonl`（题库）。

## 结论先说

**主因是「复现不忠实」（质量问题），不是「研报没公式」；但研报侧有两个真实的次要缺口。**

## 一、不是"研报没公式导致复现失败"

昨夜状态机覆盖 **20 个课题：18 reproduce_ok / 2 abandoned（通过率 90%）**。

| | 复现通过 | 未通过 | 通过率 |
|---|---|---|---|
| **有原文公式** | 10 | 0 | **100%** |
| **无原文公式** | 8 | 2 | **80%** |

→ 通过率几乎不受"有没有原文公式"影响（有公式反而更高）。所以"复现不过线"不是主要矛盾。
（注：昨夜 90% 通过；此前"44%"是**跨会话累积**的 22/50，两者口径不同，不可混用。）

## 二、核心问题：复现公式与原文公式**几乎无关**

对昨夜 10 个**有原文公式**的课题，比较复现表达式与原文公式的字段/算子集合：

| 课题 | 原文条数 | 字段 Jaccard | 算子 Jaccard |
|---|---|---|---|
| RQ_030 | 75 | 0.00 | 0.00 |
| RQ_031 | 36 | 0.04 | 0.00 |
| RQ_034 | 10 | 0.00 | 0.10 |
| RQ_035 | 10 | 0.00 | 0.00 |
| RQ_040 | 1 | 0.00 | 0.38 |
| RQ_042 | 4 | 0.00 | 0.00 |
| RQ_043 | 5 | 0.25 | 0.10 |
| RQ_046 | 36 | 0.04 | 0.12 |
| RQ_048 | 52 | 0.04 | 0.07 |
| RQ_049 | 2 | 0.25 | 0.08 |
| **平均** | — | **0.062** | **0.085** |

即：**复现出来的表达式，平均只与原文共享 6% 的字段、8.5% 的算子**。

### 四组原始对照（研报原文 ↔ 复现）

**RQ_048 华泰证券《华泰单因子测试之财务质量因子》（原文 52 条：应计/流动比率/资产周转等）**
```
原文: currentdebttodebt = DIVIDE($funda_current_liabilities, $funda_total_liabilities)
      qfa_ocftosales     = DIVIDE($funda_ocf, $funda_total_revenue)
复现: base = NEG(TS_PCTCHANGE($adj_close, 5))
      qual = RANK(CS_WINSORIZE($funda_roe, 0.01, 0.99))
      SOFT_GATE(base, qual, 0.5, true)          # 5日反转 × ROE 门控
```

**RQ_043 东方证券《反转因子择时研究》（原文：60 日反转 / CGO_3M）**
```
原文: Ret3M = TS_PCTCHANGE($close, 60)   CGO_3M = TS_PCTCHANGE($close, 60)
复现: rev = TS_PCTCHANGE($adj_close, 5)  → 5 日反转 + 换手残差化   # 窗口差 12 倍，"择时"完全没有
```

**RQ_040 光大证券《基于 K 线最短路径构造的非流动性因子》（原文：用 high/low/close 构造路径距离）**
```
原文: TS_MEAN(DIVIDE(TS_SUM(MULTIPLY(ABS(ADD(ADD(high, low), NEG(MULTIPLY(2, close)))), ...)), ...)
复现: illiq = TS_MEAN(DIVIDE(ABS($ret), $amount), 5)   # 教科书 Amihud，完全没实现"K 线路径"
```

**RQ_034 海通证券《分析师一致预期相关因子》（原文用 $pred_net_profit_mid / $ac_eps_fy 等预期字段）**
```
原文: Con_PE = DIVIDE($close, $ac_eps_fy)      Con_ROE = DIVIDE($pred_net_profit_mid, $funda_total_equity)
复现: pe_mom = TS_PCTCHANGE($pe_ttm, 20) → 市值分组残差 → 取负    # 未使用任何一致预期字段
```

## 三、结构性原因：判定标准不校验保真度

- 复现是否"通过"由**训练集统计门槛**裁决（|IC|≥0.02 且 |ICIR|≥0.2），
  **没有任何一项校验"与原文公式的保真度"**。
- 因此模型有明确激励用**容易过线的通用因子**（5 日反转、Amihud 非流动性、PE 动量、ROE 门控）
  顶替原文机制——这类因子 IC 天然容易到 0.02。
- 代码注释本身就承认了这一点：`report_channels.py:102`
  「只靠题面约束，模型可脱稿自由探索（实测产出 promising 但脱离研报血统）」。

## 四、研报侧的两个真实缺口（次要但存在）

1. **题库混杂**：1200 道题里 **294 道（24.5%）** 来自周报 / 月报 / 跟踪 / 文献推荐 / 基金研究类报告
   （如《…多因子选股周报：估值因子表现出色》《…海外文献推荐第 83 期》），这些报告**本来就没有因子公式**。
2. **抽取覆盖低**：`factor_records_pilot.jsonl` 覆盖 **299/1898 = 15.8%** 篇；
   昨夜有原文公式可用的课题恰好 **10/20 = 50%**。

## 五、建议（按性价比）

1. **把"保真度"变成硬门槛**（最关键）：复现公式必须与原文公式有最小重叠
   （字段 Jaccard ≥ 阈值，或必须命中原文 N 个核心字段之一/同一算子族），
   不达标**不算复现通过**。这直接封堵"脱稿自由探索"。
2. **题库清洗 + 优先派发覆盖集内课题**：剔除/降权无公式型报告；优先从 20.33% 的覆盖集里出题，
   保证每次复现都注入原文公式块。
3. **继续提高抽取覆盖**（15.8% → 更高），"以原文为锚"才有基础。
4. 复现判定增加**客观锚**通道：用字段/算子重叠做机械化校验，
   而非只依赖 `report_reproduce_judge` 的 LLM 主观判定。
