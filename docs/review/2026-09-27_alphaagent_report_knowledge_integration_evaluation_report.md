## 四、核心系统缺陷诊断与根治

### 1. 分箱塌缩历史治理复盘与根治
- **旧治理漏洞**：2026-09-15 曾规定“门控后末位必须包 `CS_ZSCORE`”。但数学上 `CS_ZSCORE` 是单调线性变换，80% 置零的常数点变换后依然是完全相等的常数点，无法化解等频分箱合并。
- **落地根治**：
  1. 新增连续加权门控算子 **`SOFT_GATE(signal, state, strength=0.5)`**（未激活端连续衰减而非置零，数学上消除常数簇，等频分箱永不塌缩）；
  2. 海选第一阶段增加常数簇比例前置毫秒级短路（常数占比 >25% 直接判定 `collapse_risk_rejected`，不在无效结构上浪费算力）。

### 2. 研报大题库生成与去重
- 运行抽取脚本 `scripts/extract_research_questions.py`，全量扫描 1,898 篇研报；
- 剥离免责声明与表格排版噪音，提取实证结论假说，基于语义指纹去重；
- **成功沉淀 1,042 道结构化非重复金工攻坚课题**，落库于 `data/research_reports/knowledge/research_questions.jsonl`，全面覆盖价量、量能、基本面、资金、股东、事件等 8 大维度。

### 3. 逐轮动态伴随 RAG 检索（根治认知打架）
- 此前 RAG 仅启动时粗搜一次，搜出内容常与当前派发课题脱节；
- 改造后：**每一轮开始时，以当前课题的主题和假说为 Query 触发 RAG 检索**，毫秒级召回完全同源的文献段落，考题与参考书 100% 同步同频。

## 六、未来生产开采建议

1. **跨面正交配对是破除同质化的捷径**：
   - 单一价量因子容易在 0.70 正交查重门撞车；
   - 在主课题基础上，强制引入 **量能换手率、资金流向或基本面现金流** 作为滤网（通过 `SOFT_GATE` 或 `CS_RESIDUALIZE` 融合），既能压低周度调仓换手，又能使截面向量偏转，避开查重门顺利进池。
2. **调仓机制适配**：
   - 对于日内跳空等强脉冲快信号，若要商业化交付，建议在配置中将回测调仓频率放宽至 `daily`，或强制引入 10 日以上 `WMA` / `SIGNAL_BLEND` 平滑算子。
