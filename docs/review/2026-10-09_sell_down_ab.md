## TL;DR

**结论：判定链四选一 → 选 1「默认全开（sell_down_to_target + vol_target）」，附盲测终审前置条件。**

1. **三重对齐门全过**：D0/W0（sell_down 关）与 f65d038 报告逐位一致，新增 D1id 门（vol=0.15 + sell_down 关）与上次 D1 逐位一致——sell-down 默认关 = 恒等的回归证明成立。
2. **上次 4.3 节的结构性封顶被解除**：同尺度直接对照（2024-10-08，两轮 scale 完全相同 0.4605）：次日仓位利用率 **0.9967 → 0.4854**；D1b 全部 104 个 scale<1 信号日利用率达成率 0.83、≥0.99 天数 104 → **0**、收敛滞后中位 1 天。

6. 上述改善含一个超出"减仓"范畴的语义变化：目标权重执行语义改变了组合构建行为（平均持仓 7.2 → 12.9~13.9），证据来自单段牛市样本（2024H2），**默认开必须先过盲测段单次终审 + 模拟盘验证**。

**双向调仓的代价是负的（即净节省）**，原因不在卖出端而在买入端：

1. 旧语义（D0/D1id）对已持仓按全额预算继续买入（已持仓部分不冲抵），现金被反复灌进超权持仓 → D0 的 1204 笔"现金不足/预算过小"拒单就是现金饥渴的证据；新语义对超权持仓买入预算 ≤0 直接跳过 → 买入额 243 万 → 122 万（−50%），现金转而覆盖新入场名字（D0 拒单 1204 → D_S 777）。
2. 卖出端：D1b 全窗卖出 123.4 万，其中清仓（退出名单）121.9 万 = **98.75%**，修剪（rebalanced）仅 1.55 万 = **1.25%**。3 笔减仓全部在国庆后跳空段：10-09 600575.SH（5516 元）、10-10 002091.SZ（5201 元）、10-17 300822.SZ（4744 元）——只有跳空行情能把赢家权重推出带外。
3. **最低佣金成为小额预算的主导成本**：D1b 的 427 笔买入全部按 5 元最低佣金计（名义 0.025% → 单票 ~3400 元预算下实际 ~0.147%）。scale 越低、单票预算越小，最低佣金侵蚀越重——这是实现波动压不到 1.0× 目标的主要执行摩擦，也是未来"预算过小拒单"阈值校准的关注点。
4. D1b 低于半仓天数 77 天（D0 仅 6 天）——这是 vol targeting 的预期行为（10-11 月高波动段自动低仓位），不是异常闲置。

## 七、机制发现与工程注记

1. **生效通道分解（D1b）**：买入端增量预算语义（主通道）+ 退出清仓传导（次）+ 卖出端修剪（1.25%，几乎可忽略）。功能名叫 "sell-down"，实际价值是**"目标权重跟踪执行语义"（trade-to-target）**——它同时修掉了旧语义"名单内只买不卖、超权照灌现金"的两个结构性缺陷。
2. **weight_band 是伪旋钮**：band 0.05 → 3 笔减仓、年化 17.19%；band 0.15 → 0 笔、年化 15.52%（差 1.67pp，即那 3 笔的贡献）。因为新语义下持仓权重被买入端压在目标附近、不向上漂移，出带只发生在跳空行情。调 band 无法显著改变触发率/换手（判定选项 2"默认开但 band 放宽"因此失去意义，band 维持默认 0.15 即可）。
3. **组合构建行为变化（须向用户/UI 明示）**：平均持仓 7.2 → 12.9~13.9（等权目标下更多名字实际成交）、低于半仓天数大增。这不是纯风控叠加，是执行语义变更。
4. **sell-down 独立价值（判定选项 4 的证据）**：D_S（不挂 vol target）年化 38.0%、夏普 1.251、超额 −19.7%（vs D0 −31.8%，+12.1pp），换手/费用与 D0 相当——即便不启用 vol targeting，目标权重执行语义本身在本样本有明确正贡献；vol targeting 在其上提供风险兑现层（D1b 回撤 −7.7% vs D_S −12.1%，实现波动 17.3% vs 29.1%）。
5. W3b 超额（+32.4%）反超 W0（+21.2%）：scale>1 加仓段（25% 档 25% 的信号日 scale>1，hi=1.5 封顶）在低波上行段放大了收益——上次报告"上限封顶未实际触发"的行为在双向语义下首次产生收益贡献。

## 八、结论（判定链四选一）

**选 1：默认全开（sell_down_to_target + vol_target），附前置条件。**

- val 段证据：三道门全过；四项核心指标（夏普/回撤/换手/费用）on 组全面优于 off，实现波动逼近 target，上次的结构性封顶解除，且换手/费用不升反降。
- **前置条件（强制）**：证据来自 2024H2 单段牛市样本（日频 119 信号日 / 周频 24）；且 sell-down 的实际效果一半来自执行语义变化（持仓数、成交名单、现金路径都变了）。默认开启前必须：① 盲测段单次终审；② 模拟盘（core.paper）跑通同参数透传路径（1bd3e60 已同步 rebalance.py，需实盘口径验证）。
- 分档建议：若 UI 暴露档位，日频口径 15~20% 档（回撤优先）或 25% 档（收益优先，D3b 年化 36.5%）；周频口径建议 25% 档起步（15% 档超额损耗 19pp，本样本不划算）。
- **选项 2（默认开但 band 放宽）被数据否定**：band 0.05 vs 0.15 差异仅 3 笔减仓 +1.67pp 年化，不是有效旋钮，维持默认 0.15。
- **选项 4（sell-down 独立开）部分成立**：若产品上不愿动风险档位，sell-down 单开已有 +12pp 超额改善与换手/费用中性；它与 vol_target 解耦可用，但两者叠加才是完整的风险承诺兑现。

给实现的工程反馈（超出本 A/B 范围，供 Lead/用户决策）：① "预算过小"拒单（D1b 822 笔）与最低佣金 5 元的相互作用值得校准（比如最低预算阈值随 min_commission 联动），这是实现波动压到 1.0× 的最后一段摩擦；② rebalanced 减仓的 status/reason 标记（"rebalanced"/"sell_down"）清晰可审计，便于后续按通道归因。
