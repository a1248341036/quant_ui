# 研报模式：复现目标改为「结构」+ 血统门禁（2026-10-02 夜）

> 分支：`feat/question-structure-gate`（代码）/ `feat/question-schema-v2`（抽取与工具）
> 触发：用户质疑「不可能靠那些简单的一行因子算子就有效果」→ 回筛 → 改 → 整夜挖掘边看边改

## 一、问题定性（用数据，不靠感觉）

### 1.1 简单因子确实无效（26,707 次历史评估，167 个 run）

| 分组 | n | 均值\|IC\| | 均值\|ICIR\| | **达双门槛**(\|IC\|≥0.02 且 \|ICIR\|≥0.28) |
|---|---|---|---|---|
| 0 算子（裸字段） | 1 | 0.0039 | 0.047 | 0.0% |
| **1 算子** | 70 | 0.0047 | 0.057 | **1.4%** |
| 2–3 算子 | 1,823 | 0.0060 | 0.073 | **0.3%** |
| **4+ 算子** | 24,813 | 0.0122 | 0.142 | **8.2%** |
| **含结构/交互算子** | 21,601 | 0.0127 | 0.149 | **9.1%** |
| 无结构算子 | 5,106 | 0.0076 | 0.088 | 1.9% |
| 1 字段 | 2,552 | 0.0057 | 0.062 | **0.1%** |
| 3+ 字段 | 17,596 | 0.0135 | 0.160 | **11.2%** |

→ 结论：**「复现研报里那条简单公式」这个目标本身错了**——必然产出无效因子。
研报的价值在**结构**（门控/合成/残差/择时/跨面），不在那条公式。

### 1.2 回筛：报告里有多少「可复现结构」

- 机械口径（关键词）**无区分度**（73% 判有结构）→ 弃用；
- **LLM 判定**（40 篇样本）：有原文公式的报告 **14/20=70%**、随机报告 **10/20=50%** 有可复现结构；
- LLM 给出的目标具体可执行，例：「GMSD 前 2/3 → SIRD 前 50% → PB 最低 1/3 三步筛选」。

### 1.3 A/B：题面「给公式」vs「只给描述+要素清单」（17 篇 × 2 组）

| | A 给原文公式 | **B 只给描述+要素清单** |
|---|---|---|
| 合法表达式 | 17/17 | 16/17 |
| **与原公式逐字相同** | **15/17（照抄）** | 11/17（65% 自行复现出原式） |
| 算子重叠 | 88% | **80%** |
| 字段重叠 | 90% | **90%** |

→ 给公式的唯一确定性作用是「让模型照抄」，且**抽错会 100% 传染**；描述驱动已达同等字段重叠。

### 2.1 锚的校准过程（重要：不要重复犯错）

同一晚连续加强锚 → **回放实测发现过严**：把 run 里 106 条真实复现表达式回放，
拦截 19~22 条（~20%），**且误杀 live 已过线案例**。两次放松后：

```
终态：拦截 8/106（7.5%）；误杀 live 已过线案例 0 条
```
**保留的硬门**：① 声明的 `structure_ops` 命中 ② 弱声明复杂度地板。
**降为诊断**：「必须命中声明字段」「复现字段总数 ≥ min_fields」——两者都依赖 LLM 声明值、
常虚高（实测某题声明 `min_fields=5` 而 2 字段即可表达结构）。
工具：`scripts/replay_anchor_on_run.py`（改锚必跑：验收标准 = 误杀 0 且一行式被拦）。

### 2.2 血统门禁的发现

本夜首个 run 的 **12 个达双门槛因子全部是同一个父本**（`mix_ovlead_wma5_kg90_totcap_m15`）
的同根变体，而该父本来自 `memory_suggest`（记忆建议），**不是研报复现版** →
「9.6% 达双门槛」是**同根灌水读数**，研报血统被绕过。
根因：`reproduce_of_required` / `diverge_parent_required` **从未出现在配置中心** →
`agentscope_tools.py:680/689` 里早已写好的 ⛔ 拦截**一直是关闭的**。
