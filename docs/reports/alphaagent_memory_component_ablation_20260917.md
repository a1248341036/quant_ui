## 一、 实验设计

### 1.1 目的

整体消融（A1 空库）已证明记忆层整体有效（无记忆吞吐 5.38 vs Control 2.80 eval/min，见
`docs/reports/alphaagent_mining_ablation_20260915.md`）。本实验进一步定位**记忆层内部
哪个组件贡献了价值、哪个是负担**，为后续精简/降权提供依据。

### 1.2 方法

- **Control**：全记忆基线（默认配置，7 注入 + 3 写入 + 2 校准全开）
- **12 个组件 arm**：每个 arm 关闭一个组件（M1-M12），其余保持默认
- **共享记忆库快照**：所有 arm 从同一份生产记忆库快照起跑（`memory_snapshot.db`，
  71MB，含历史积累），保证"关掉组件"与"没有历史可检索"可区分
- **隔离**：每个 arm 独立记忆库副本，写入不回流生产库
- **评估指标**：复用 `generate_scorecard`（schema_version 3），主裁决 = 探索广度与效率

### 1.3 执行情况

| 项 | 计划 | 实际 |
| :--- | :--- | :--- |
| 重复次数 | 3 次 | **1 次**（时间受限） |
| 每 arm 轮次 | 30 轮 | **1 轮**（约 20 分钟/arm） |
| 并行度 | 3 | **串行**（并行 4 时 LLM 500 限流致 10/11 arm 中断） |
| 完成度 | 13/13 | 13/13（但 control 仅 2 轮对话被中断） |
| 组合验证 | — | **OPT_effective_only**（只保留有效块，1 轮，2026-09-17 补跑） |
| control 补跑 | — | **control 完整轮次**（21 轮、137 次尝试，2026-09-17 补跑） |

> **重要限制**：control 首跑因 LLM 500 中断只跑了 2 轮对话（63 次尝试、7.5 万 token），
> 其余 arm 均跑满 1 轮（20+ 轮对话、100 万+ token）。**首跑 control 与其他 arm 样本量
> 不可比**，报告初版所有"消融组 vs control"对比均为**方向性参考**。
> 2026-09-17 已补跑 **control 完整轮次**（21 轮、137 次尝试、吞吐 7.85/min）作为可比
> 基线，并补跑 **OPT_effective_only** 组合 arm（19 轮、117 次尝试）。**后续对比以
> 完整 control 为准**。

## 三、 逐组件判读

> 判读纪律（spec §五）：单轮数据、无重复方差，所有结论标注"方向性"；"消融组不差"
> 不直接解读为"该机制是负担"。

### M1 无证据块（`enable_factor_retrieval=False`）

| 指标 | control | M1 | 方向 |
| :--- | ---: | ---: | :--- |
| 尝试数 | 63 | 34 | ↓ |
| 吞吐 | 6.02 | 3.36 | ↓ |
| 未提交 promising | 0 | 11 | ↑ |

**方向性结论**：证据块是记忆核心，关闭后探索广度显著下降（34 vs 63），且出现 11 个
"训练过线但未提交"的决策断层。**证据块有效，保留**。与 spec 假设一致（M1 关掉后
探索退化 → 证据块是核心资产）。

### M2 无经验块（`enable_experience_block=False`）

| 指标 | control | M2 | 方向 |
| :--- | ---: | ---: | :--- |
| 尝试数 | 63 | 71 | ↑ |
| 吞吐 | 6.02 | 1.91 | ↓↓ |
| 有效尝试比 | 0.789 | 0.973 | ↑↑ |
| 撞死路% | 11.3 | 2.7 | ↓ |

**方向性结论**：关闭经验块后**有效尝试比大幅提升**（0.973 vs 0.789）、撞死路率下降
（2.7% vs 11.3%），但吞吐暴跌（1.91 vs 6.02，墙钟 37.7 分钟最长）。经验块注入的
"成功模式/禁忌方向"可能**引入无效尝试**（LLM 照抄模板但参数不达标），同时拖慢探索。
**经验块疑似负资产，建议降权或精简**——但需重复验证（M2 墙钟异常长，可能受 LLM 500
重试影响）。

### M3 无编辑先验（`enable_edit_patterns=False`）

| 指标 | control | M3 | 方向 |
| :--- | ---: | ---: | :--- |

**方向性结论**：关闭编辑先验后**探索广度大幅提升**（186 vs 63，3 倍），有效尝试比
提升、撞死路率下降。编辑先验可能**压制跨领域发现**（LLM 被父本变异建议框住）。
**编辑先验疑似压制探索，建议降为可选或降权**——与 spec 假设"编辑先验压制跨领域
发现"方向一致。

**方向性结论**：关闭饱和度块后吞吐提升（7.11 vs 6.02）、探索广度翻倍，但撞死路率

## 三b、 组合验证：OPT_effective_only（只保留有效块）

### 3b.1 配置

基于逐组件判读，把"疑似负资产/存疑"的 6 个块全部关闭，只保留"有效"的 5 个块：

| 保留（有效块） | 关闭（负资产/存疑块） |
| :--- | :--- |
| 证据块（M1） | 经验块（M2） |
| 产出率块（M5） | 编辑先验（M3） |
| 多样性块（M6） | 饱和度块（M4） |
| 经验蒸馏（M11） | 结构命中率块（M7） |
| advisory 缓存（M12） | APV 否决（M8） |
| | SSPM 写入（M10） |

即 `memory_policy` 覆盖：`enable_experience_block=False, enable_edit_patterns=False,
enable_saturation_block=False, enable_structure_stats_block=False, apv_tau_c=1.0,
apv_tau_v=1.0, enable_sspm_write=False`。

### 3b.2 结果

| 指标 | control（完整） | OPT | 变化 |
| :--- | ---: | ---: | :--- |
| 尝试数 | 137 | 117 | -15% |
| 吞吐/min | 7.85 | 5.66 | -28% |
| 撞死路% | 5.4 | **1.5** | **-72%** |
| 对账确认率% | 43.9 | 43.0 | ≈持平 |
| 未提交 promising | 11 | **0** | **-100%** |
| near_miss | 11 | 9 | -18% |
| 对话轮 | 21 | 19 | — |
| 墙钟(min) | 18.6 | 24.2 | — |

### 3b.3 判读

**只保留有效块的组合 arm 在撞死路率与决策断层上优于完整 control，但吞吐与探索广度略逊**：

- **撞死路率 -72%**（1.5% vs 5.4%）：重复死路大幅减少——负资产块（尤其结构命中率块
  引导的模板惯性）是死路的主要来源
- **无决策断层**（未提交 promising=0 vs control 11）：OPT 下 LLM 过线即提交，
  不出现"训练过线但未提交"的断层
- **对账确认率持平**（43.0% vs 43.9%）：精简记忆不损失机制假设质量
- **吞吐 -28%**（5.66 vs 7.85）：关闭负资产块后 LLM 探索更自由但更慢（每轮评估
  决策时间变长）
- **探索广度 -15%**（117 vs 137 次尝试）：与吞吐下降一致

> **修正**：报告初版基于 2 轮 control（63 次尝试）得出"OPT 全面优于 control"的结论，
> 其中"对账确认率 +258%"是 control 样本不足的假象。补跑完整 control（137 次尝试）
> 后，OPT 的真实优势收敛为**撞死路率 -72% + 无决策断层**，代价是**吞吐 -28%**。
> 方向性结论仍成立（OPT 在质量维度更优），但"精简记忆不损失效率"的说法不成立——
> 精简后吞吐确实下降。

## 四、 与整体消融的衔接（spec §六）

### 4.1 待修复项交叉验证

| 待修复项 | 相关组件 | 本实验验证点 | 结果 |
| :--- | :--- | :--- | :--- |
| 待修复 1（决策断层） | advisory 死路拦截 + duplicate_prior_result | M9 应显示决策断层下降 | M9 未提交 promising=10，control=0，**未验证**（control 样本不足） |
| 待修复 2（吞吐黑洞） | 条目写入 + SSPM 写入 + advisory 缓存 | M10 + M12 应显示吞吐提升 | M10 吞吐 4.55、M12 吞吐 4.10，均**低于** control 6.02，**未验证** |
| 待修复 3（低换手） | 经验蒸馏 + 检索正向保底 | M11 应显示低换手模板注入减少 | M11 撞死路率 3.8% 低于 control 11.3%，**部分验证** |

> 待修复 1/2 未验证主因是 control 样本不足（仅 2 轮对话），无法作为可比基线。

### 4.2 与整体消融结论的一致性

整体消融（A1 无记忆）结论：记忆层整体有效（吞吐 5.38 vs 2.80）。本实验进一步发现：
- **记忆层内部并非全正资产**：M2（经验块）、M7（结构命中率块）、M8（APV 否决）
  关闭后探索广度/吞吐反而提升，提示这三个组件可能是**负资产或需降权**
- **记忆层的价值集中在**：证据块（M1）、产出率块（M5）、多样性块（M6）、经验蒸馏
  （M11）、advisory 缓存（M12）——关闭后出现决策断层或吞吐下降

## 五、 结论与建议

### 5.1 结论（方向性，需重复验证）

| 组件 | 判定 | 建议 |
| :--- | :--- | :--- |
| 证据块 | **有效**（核心） | 保留，可优化注入密度 |
| 经验块 | **疑似负资产** | 降权或精简（有效尝试比 0.973 vs 0.789） |
